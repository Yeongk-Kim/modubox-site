## 방송
- **방송 번호를 바꾸려면** — (스마트형) 번호판에서 번호를 길게 눌러 다른 번호 위에 놓으면 두 방송의 번호가 서로 바뀝니다. (레트로형) 설정 › 번호 순서 조정에서 바꿀 수 있습니다.
- **방송을 다시 찾으려면** — 나오지 않는 방송이 있으면 설정 › 자동 채널 찾기를 누르면 됩니다. 이사를 하셨으면 그 화면 맨 위의 사는 곳을 먼저 바꿉니다.
- **멈춤 버튼을 쓰려면** — 누르면 멈추고, 다시 누르면 이어서 나옵니다. 길게 누르고 있으면 꺼집니다. 멈춘 상태로 30분이 지나면 저절로 꺼집니다.
- **재생 화면을 쓰려면**(스마트형) — 목록이나 번호판에서 누르면 그 방송의 재생 화면이 열립니다. 둥근 조작판으로 ⌂ 홈 · ⏮ 앞 방송 · ❚❚ 멈춤 · ⏭ 다음 방송 · ↩ 앞 화면으로 갑니다. 가운데 단추를 길게 누르면 꺼집니다.
- **듣는 카드를 쓰려면**(스마트형) — 화면 아래에 지금 나오는 것이 카드로 섭니다. 오른쪽 단추는 누르면 멈추고 다시 누르면 이어서 나오며, 길게 누르면 꺼지면서 카드가 사라집니다. 카드를 누르면 재생 화면으로 갑니다.
- **자동 끄기를 걸려면** — 타이머 단추를 누를 때마다 1시간 → 2시간 → 3시간 → 꺼짐(스마트형은 재생 화면 맨 아래 기호 줄, 레트로형은 화면 맨 위 손전등과 설정 사이). 걸어 둔 뒤 3초가 지나서 다시 누르면 바로 꺼집니다.

## 팟캐스트 · 유튜브 (스마트형)
- **팟캐스트를 들으려면** — 팟캐스트 쪽에서 분야를 고르고 프로그램을 누르면 회차 목록이 나옵니다. 듣던 회차는 멈춘 자리부터 이어 듣습니다.
- **유튜브를 보려면** — 유튜브 쪽에서 방송사 공식 채널을 누르면 앱 안에서 바로 봅니다. 화면을 떠나면 멈춥니다.
- ※ 팟캐스트와 유튜브는 화면 언어가 한국어일 때 보입니다(한국 방송사 목록이라서).

## 내 음악 (레트로형)
- **들을 노래를 고르려면** — 설정 › 내 음악 고르기에서 폴더나 노래를 체크한 뒤 [저장]을 누릅니다.
- **랜덤·반복으로 들으려면** — 설정 맨 위의 [랜덤 듣기]·[한 곡 반복]을 누릅니다. 랜덤은 한 바퀴 도는 동안 같은 노래가 다시 나오지 않고, 번호와 순서는 그대로입니다.
- ※ 스마트형에서는 PRO의 즐겨찾기 [＋ 내 음악]으로 폰 속 노래를 담아 듣습니다.

## 즐겨찾기
- **담으려면** — 방송·팟캐스트 프로그램·유튜브 채널은 목록 줄이나 재생 화면의 ☆를 한 번 누르면 담깁니다. 여기까지는 무료입니다.
- **정리하려면** — 항목을 길게 누르면 이름 바꾸기와 빼기가 나타납니다. 길게 눌러 끌면 순서를 바꿀 수 있습니다.

## 홈(스마트형)
- **아이콘 자리를 옮기려면** — 아이콘을 길게 누른 채 원하는 자리로 끌어 놓으면 됩니다.
- **아이콘을 빼려면** — 아이콘을 길게 눌렀다가 그 자리에 놓으면 휴지통 표시가 나타납니다. 누르면 홈에서 빠집니다. 라디오·즐겨찾기·설정은 뺄 수 없습니다. 뺀 앱은 설정 › 홈 앱 추가에서 다시 넣을 수 있습니다.
- **폴더로 모으려면** — 아이콘을 다른 앱 위에 잠시 올려 두면 테두리가 나타납니다. 이때 손을 떼면 폴더가 만들어집니다.
- **앱을 홈에 넣으려면** — 설정 › 홈 앱 추가의 '기본 앱'에서 앱을 누르면 홈에 들어가고, 다시 누르면 빠집니다. 처음부터 놓여 있던 칸은 무료로 빼고 다시 넣을 수 있고, 꺼져 있던 앱을 새로 켜는 것은 PRO입니다.

## 화면
- **화면 모양·색을 바꾸려면** — 설정 › 화면 모양 · 색. 레트로형은 라디오 모양으로 번호만 누르면 되고, 스마트형은 아이콘으로 된 화면입니다. 설정은 (스마트형) 메뉴 탭 줄 오른쪽 끝의 ⋮로, (레트로형) 머리글의 ⚙로 엽니다.
- **잠들 때 소리를 들으려면** — (스마트형) 홈의 수면 사운드를, (레트로형) 스피커 무늬 왼쪽 위의 수면 아이콘을 누르고 빗소리·파도·시냇물·모닥불이나 노이즈를 고릅니다. 정한 시간이 지나면 소리가 서서히 작아지며 꺼집니다.

## PRO
- **무료와 PRO가 어떻게 다른지** — 라디오·팟캐스트·유튜브·방송 ☆·처음 놓인 홈 칸·자동 끄기·라디오 알람·화면 모양·색·사진·걸음 수와 레트로형 내 음악은 무료로 계속 씁니다. PRO는 즐겨찾기 넓히기(폰 속 내 음악, 다른 앱에서 [공유]로 담기), 홈 앱 추가, 어학·오디오북, 예약 알림, 말소리 또렷하게이고 한 번 구입입니다. 설정 › PRO 기능 알아보기에서 7일 동안 무료로 써 볼 수 있고, 체험은 한 번이며 끝나도 저절로 결제되지 않습니다.
- **다른 앱의 것을 담으려면** — 유튜브·팟빵·인터넷 창에서 [공유] › 모두박스.
- **즐겨찾기에 내 음악을 담으려면** — 즐겨찾기 맨 위 [＋ 내 음악]에서 폰 속 노래를 ☆로 고릅니다.
- **홈에 다른 앱을 넣으려면** — 설정 › 홈 앱 추가의 '내 애플리케이션'에서 [추가] → 앱 고르기 → [저장]. 홈 빈 칸만큼 넣을 수 있습니다.
- **예약 알림을 걸려면** — 재생 화면 정보 줄 끝의 🔔를 누르면 그 프로그램이 시작하기 3분 전에 매주 알려 드립니다. 목록은 설정 › 예약 알림입니다.
- **말소리를 또렷하게 들으려면** — 설정 › 말소리 또렷하게 스위치를 켜면 진행자 목소리가 또렷해집니다.
- **라디오 알람을 맞추려면**(무료) — 설정 › 라디오 알람에서 ＋ → 시각·방송·요일 → [저장]. '소리 점점 크게'를 켜 두면 작은 소리부터 켜집니다.
- ※ 유튜브·스포티파이 같은 앱은 모두박스가 열어 주기만 합니다. 그 앱의 구독·이용권은 각 앱에서 따로 해야 합니다.

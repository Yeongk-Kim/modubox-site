우리가 지키는 것

  • 회원가입 없이 — 앱을 열면 바로 씁니다.
  • 모으지 않습니다 — 개인정보와 사용 기록을 수집하지 않습니다. 이 웹사이트에도 방문 추적·쿠키·광고가 없습니다.
  • 유료 기능은 PRO 하나로 — 모든 앱에서 같은 이름을 쓰고, 기본 기능은 무료로 둡니다.
  • 과장하지 않습니다 — 확인되지 않은 수치나 지어낸 후기를 쓰지 않습니다.
  • 남의 것은 남의 것대로 — 방송과 영상은 공개된 공식 경로로 연결해 재생만 하고, 저장하지 않습니다.

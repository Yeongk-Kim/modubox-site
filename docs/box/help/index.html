수면 사운드모두박스

도움말 — 모두박스

방송

  • 방송 번호를 바꾸려면 — (스마트형) 번호판에서 번호를 길게 눌러 다른 번호 위에 놓으면 두 방송의 번호가 서로 바뀝니다. (레트로형) 설정 › 번호 순서 조정에서 바꿀 수 있습니다.
  • 방송을 다시 찾으려면 — 나오지 않는 방송이 있으면 설정 › 자동 채널 찾기를 누르면 됩니다. 이사를 하셨으면 그 화면 맨 위의 사는 곳을 먼저 바꿉니다.
  • 멈춤 버튼을 쓰려면 — 누르면 멈추고, 다시 누르면 이어서 나옵니다. 2초 동안 누르고 있으면 꺼집니다. 멈춘 상태로 30분이 지나면 저절로 꺼집니다.
  • 카드 위 단추를 쓰려면(스마트형) — 시계 단추는 정한 시간이 지나면 저절로 꺼지게 하고, ☆는 지금 나오는 것을 즐겨찾기에 담습니다. 내 음악·즐겨찾기에서는 아래 단추 줄 양 끝에 랜덤과 반복(누를 때마다 꺼짐 → 전체 반복 → 한 곡 반복)이 섭니다.

내 음악

  • 들을 노래를 고르려면 — (스마트형) 내 음악 목록 위 오른쪽의 폴더 단추를 누르고 폴더나 노래를 체크한 뒤 [저장]을 누릅니다. (레트로형) 설정 › 내 음악 고르기에서 고릅니다.
  • 랜덤으로 들으려면 — 아래 단추 줄 왼쪽 끝의 랜덤 단추를 누르면 노래가 랜덤 순서로 나옵니다. 한 바퀴 도는 동안 같은 노래가 다시 나오지 않고, 번호와 순서는 그대로입니다.
  • 노래 순서를 바꾸려면 — 내 음악에서 노래를 길게 눌러 원하는 자리로 끌어 놓으면 됩니다.

즐겨찾기

  • 담으려면 — 듣고 계신 방송·노래는 ☆를 한 번 누르면 담깁니다.
  • 정리하려면 — 항목을 길게 누르면 이름 바꾸기와 빼기가 나타납니다. 길게 눌러 끌면 순서를 바꿀 수 있습니다.

홈(스마트형)

  • 아이콘 자리를 옮기려면 — 아이콘을 길게 누른 채 원하는 자리로 끌어 놓으면 됩니다.
  • 아이콘을 빼려면 — 아이콘을 길게 눌렀다가 그 자리에 놓으면 휴지통 표시가 나타납니다. 누르면 홈에서 빠집니다. 라디오·내 음악·즐겨찾기·설정은 뺄 수 없습니다. 뺀 앱은 설정 › 홈 앱 추가에서 다시 넣을 수 있습니다.
  • 폴더로 모으려면 — 아이콘을 다른 앱 위에 잠시 올려 두면 테두리가 나타납니다. 이때 손을 떼면 폴더가 만들어집니다.
  • 앱을 홈에 넣으려면 — 설정 › 홈 앱 추가의 '기본 앱'에서 앱을 누르면 홈에 들어가고, 다시 누르면 빠집니다.
  • 다른 앱으로 연 것 — 유튜브·음악 앱처럼 다른 앱으로 연 것은 창에 '○○에서 재생 중'으로 나오고, 아래 단추로 멈추거나 넘길 수 있습니다.

화면

  • 화면 모양·색을 바꾸려면 — 설정 › 화면 모양 · 색. 레트로형은 라디오 모양으로 번호만 누르면 되고, 스마트형은 아이콘으로 된 화면입니다. (레트로형) 도움말은 ⋮ 더보기 › 도움말에서도 볼 수 있습니다.
  • 잠들 때 소리를 들으려면 — (스마트형) 홈의 수면 사운드를, (레트로형) 모드 줄의 [수면]을 누르고 빗소리·파도·시냇물·모닥불이나 노이즈를 고릅니다. 정한 시간이 지나면 소리가 서서히 작아지며 꺼집니다.

PRO

  • 무료와 PRO가 어떻게 다른지 — 라디오·내 음악·홈 기본 앱·즐겨찾기(☆)·자동 끄기·화면 모양·색·사진·걸음 수는 무료로 계속 씁니다. PRO는 다른 앱에서 즐겨찾기 담기, 내 애플리케이션, 라디오 알람, 말소리 또렷하게이고 한 번 구입입니다. 설정 › PRO 기능 알아보기에서 7일 동안 무료로 써 볼 수 있고, 체험은 한 번이며 끝나도 저절로 결제되지 않습니다.
  • 유튜브·팟캐스트를 담으려면 — 유튜브·팟빵·인터넷 창에서 [공유] › 모두박스.
  • 내 애플리케이션을 홈에 넣으려면 — 설정 › 홈 앱 추가의 '내 애플리케이션'에서 [추가] → 앱 고르기 → [저장]. 홈 빈 칸만큼 넣을 수 있습니다.
  • 말소리를 또렷하게 들으려면 — 설정 › 말소리 또렷하게 스위치를 켜면 진행자 목소리가 또렷해집니다.
  • 라디오 알람을 맞추려면 — 설정 › 라디오 알람에서 ＋ → 시각·방송·요일 → [저장]. '소리 점점 크게'를 켜 두면 작은 소리부터 켜집니다.
  • ※ 유튜브·스포티파이 같은 앱은 모두박스가 열어 주기만 합니다. 그 앱의 구독·이용권은 각 앱에서 따로 해야 합니다.

잘 안 될 때

아래 '자주 묻는 질문'에 모아 두었습니다.

자주 묻는 질문

회원가입이 필요한가요?

아닙니다. 받아서 바로 씁니다. 모두박스는 이용자 정보를 저희 서버로 보내지 않습니다.

데이터는 얼마나 쓰나요?

방송마다 다르지만 대개 한 시간에 30~60MB 정도입니다. 와이파이에서 들으시면 데이터 걱정이 없습니다.

아이폰에서도 되나요?

지금은 안드로이드 폰만 됩니다.

방송이 자꾸 끊겨요

와이파이나 데이터 신호를 먼저 확인해 주세요. 다른 앱이 소리를 내서 멈춘 경우에는 모두박스로 돌아오면 다시 나옵니다. 화면을 끈 뒤 멈춘다면 아래 '화면을 끄면 얼마 뒤 멈춰요'를 봐 주세요.

화면을 끄면 얼마 뒤 멈춰요

폰의 배터리 절약이 앱을 멈추는 경우입니다. 폰 설정 › 애플리케이션 › 모두박스 › 배터리에서 '제한 없음'(기종에 따라 '최적화 안 함')으로 바꿔 주세요.

소리가 안 나요

폰의 미디어 소리 크기를 확인해 주세요. 블루투스 이어폰·스피커가 다른 기기에 연결돼 있지 않은지도 봐 주세요.

어떤 방송이 안 나와요

설정 › 자동 채널 찾기를 한 번 눌러 주세요. 방송사 사정으로 잠시 안 나오는 방송도 있습니다.

## 왜 홈페이지 저장소인가

한국에서는 **'한국에서 받아진다'까지만** 알 수 있습니다. 교민이 쓰는 자리
(미국)에서 그 주소가 열리는지는 **미국에서 열어 봐야** 압니다.
깃허브가 주는 러너(`ubuntu-latest`)가 **미국에 있어서** 그 자리를 공짜로
한 번 빌리는 것입니다 — 유튜브 채널 점검과 **같은 생각·같은 틀**입니다
(`../youtube_check/`).

⚠ **러너는 데이터센터 IP 입니다 — 가정용 망과 다를 수 있습니다.**
방송사가 '데이터센터는 막고 가정용은 열어 두는' 경우도, 그 반대도
있습니다. 그래서 이 표는 **교민 베타 한 분('가')이 폰에서 보는 것과
함께** 읽어야 합니다. 이 표 하나로 `channels.json` 의 `overseas` 칸을
곧바로 고치지 않습니다.

⚠ **영상(유튜브)은 여기서 재지 않습니다** — 러너 IP 로는 유튜브 재생이
막힙니다(보는 라디오 전달문 127에서 통과 0/49). 영상 쪽은 옆 묶음
(`../youtube_check/check_region.py`)이 **공식 API 로 설정 값**
(`regionRestriction` · `embeddable`)만 읽습니다 — 재생을 흉내 내지
않습니다.

## 하는 일 — 두 걸음이다 (조회 → 재생)

국내 방송사 넷(**KBS · MBC · SBS · cpbc**)은 **지금 재생 주소를 한 번 더
물어봅니다**. 점검기는 앱 부품 `StreamResolver` 와 **같은 뜻**으로 풉니다:

| `streamLookup` | 푸는 법 | 몇 카드 |
|---|---|---|
| `{"kind":"json","path":"channel_item.0.service_url"}` | KBS — JSON 의 그 자리 | 7 |
| `{"kind":"json","path":"onair.source.mediasource.mediaurl"}` | SBS · cpbc — 같은 길, 자리만 다름 | 4 |
| `{"kind":"text"}` | MBC — 몸통이 곧 주소(sredirect) | 3 |
| 없음 | `streamUrl` 이 **바로 재생 주소** | 26 |

⚠ **그래서 결과를 두 단계로 가릅니다** — `조회 거절`(① 방송사 API 가
막았다)과 `소리 거절`(② 조회는 됐는데 그 주소가 막혔다)은 **다른
일**입니다. '해외에서 막힌 것'과 '그냥 죽은 주소'를 가르려면 이 구분이
있어야 합니다.

| 결과 | 뜻 |
|---|---|
| **열림** | 소리가 **512바이트** 넘게 흘렀다 |
| **조회 거절** | ① 방송사 **조회 API** 가 막았다(해외 막힘이면 여기일 때가 많다) |
| **소리 거절** | ② 조회는 됐는데 **그 소리 주소**가 막혔다 |
| **시간 초과** | **8초** 안에 답이 없었다 |

### HLS(`.m3u8`)는 **첫 조각 하나까지** 갑니다

재생목록은 글이라 그것만 받아서는 '소리가 흘렀다'고 할 수 없습니다.
재생목록 → (여러 품질이면) 첫 갈래 → **첫 조각**까지 받아 봅니다.

### 한 번에 받는 양

| | |
|---|---|
| 소리 | **2KB 까지**(`MAX_BODY`) · 한 걸음 **8초** |
| 조회 응답 · 재생목록 | **64KB 까지**(글이다) |
| 보내는 값 | **0** — 주소만 열어 봅니다(사용자 정보도 식별 값도 싣지 않습니다) |
| 비밀값 | **0** |
| **한 주 데이터** | **약 370KB**(11/21 한국에서 **실측** 372KB · 40 카드) — 표 맨 위에 그날 받은 양이 적힙니다 |

⚠ 소리 번호를 **나눠 쓰는 카드**가 있습니다(`mbc-trot` 과 `mbc-sfm` 이
둘 다 `kr-mbc-sfm`). 표에는 줄이 둘이지만 **한 번만** 열어 봅니다.

⚠ **`ICY 200 OK` 를 받아야 합니다** — Radio Korea LA(LA 최대 한인 방송)는
SHOUTcast 서버라 첫 줄이 보통 HTTP 가 아니고, `urllib`·`curl` 은 그대로
터집니다. 그래서 **소리를 받는 자리**는 **생 소켓 + TLS** 로 한 줄을 직접
읽습니다(조회·재생목록은 보통 HTTP 라 `urllib` 그대로입니다).
이 자리를 고치실 때 **반드시 함께 보십시오** — `--selftest` 가 그 줄을
잽니다.

### 알리는 때

| | |
|---|---|
| 결과가 **달라진 날** | 표(`report.md`)와 실패 횟수를 커밋 |
| 열리지 않은 주소가 있으면 | **이슈 하나** |
| **두 주 잇달아** 열리지 않으면 | 그 이슈에 '사람이 볼 것'으로 따로 적습니다 |
| 다 열린 날 | 표에 **잰 날·받은 양·걸린 시간만** 바뀌므로 **커밋하지 않습니다** |

⚠ **주소를 저절로 고치거나 빼지 않습니다.** 빼고 넣는 일은 보는 라디오
쪽에서 사람이 합니다(`assets/audio_streams_ours.json` 한 줄).

## 바뀌면

보는 라디오에 카드가 늘거나 소리 주소가 바뀌면, 보는 라디오 세션이

```
python tools/build_overseas_check.py
```

를 한 번 돌려 **새 `streams.json`** 을 이 폴더에 넣고 전언을 남깁니다.
그때 그 파일 하나만 바꿔 넣으시면 됩니다(점검기·액션은 그대로입니다).

## 시험

```
python tools/overseas_check/check_overseas_sound.py --selftest
```

**바깥에 연결하지 않고** 셈만 잽니다 — `ICY 200 OK` · `HTTP/1.1 200` ·
403·404·쓰레기 첫 줄, 머리글 읽기, **조회 세 가지 풀기**(KBS·SBS·MBC),
`http` → `https` 바꾸기, **HLS 재생목록 따라가기**, 시간 초과 가리기,
https 가 아닌 주소를 열지 않는 것. 액션도 점검 **앞에** 이것을 한 번
돌립니다.
